# Endless Runner Unity

A complete, code-generated endless runner for **Unity 2022.3.62f2**. No external packages or art assets are required: the game creates its player, track, obstacles, coins, lighting, camera, and UI at runtime from Unity primitives.

## Start the game

1. Download or clone this repository.
2. Open it with Unity Hub using **Unity 2022.3.62f2**.
3. Open `Assets/Scenes/Main.unity`.
4. Press **Play**.

## Controls

- **A / Left Arrow**: move left
- **D / Right Arrow**: move right
- **Space / Up Arrow**: jump
- **R**: restart after a crash
- On mobile, swipe left/right/up.

The runner accelerates over time, the track recycles endlessly, obstacles and coins are procedurally generated, and the best score is saved with `PlayerPrefs`.
